# STM32-CAN-Monitor

## 1. 项目介绍

基于 STM32F103C8T6 的嵌入式多任务监控系统。

使用 FreeRTOS 实现多任务调度，
通过 CAN 总线实现设备间通信，
通过 USART 实现调试信息输出。

## 2. 开发环境

- MCU: STM32F103C8T6
- IDE: Keil MDK
- Language: C
- Library: STM32 Standard Peripheral Library
- RTOS: FreeRTOS
- Version Control: Git

## 3. 项目功能

- [x] GPIO 驱动
- [x] USART 串口通信
- [x] FreeRTOS 基础任务调度
- [ ] CAN 通信
- [ ] 消息队列
- [ ] 互斥锁
- [ ] 系统运行监控
